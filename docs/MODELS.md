# 模型与结果说明

## 研究问题

[主论文](../paper/paper.tex)比较三种地月物流策略：仅太空电梯、仅火箭，以及两者并行运输。建设阶段的总运输需求为 `1e8` 吨，论文同时讨论 100,000 人月球基地的水资源与环境问题。

## 时间与成本权衡

Q1 以工期 `T`、成本 `C` 为变量，在运输容量约束下生成可行解。将时间与成本分别归一化为 `f1`、`f2`，再扫描权重 `alpha`，最小化：

```text
F = alpha * f1 + (1 - alpha) * f2
```

权重越偏向时间，选择越倾向短工期。原脚本还比较不同权重下的目标值并给出推荐结果。不同权重代表不同偏好，跨权重比较目标值本身并不能证明某个权重客观最优，解读时应结合决策偏好。

论文记录的混合方案使用约 71.03% 太空电梯运量与 28.97% 火箭运量，对应工期约 132.44 年、总成本约 `5.689e13` USD。这些是原报告数值，本次未重跑验证。

## 风险与模拟

Q2 的关键参数以脚本赋值为准：

| 参数 | 脚本值 | 含义 |
| --- | ---: | --- |
| `W0` | 100,000,000 | 总运量，吨 |
| `w_R` | 1,500 | 10 个基地的等效火箭运力，吨 |
| `c_R` | 37,000 | 火箭单次等效成本，万美元 |
| `t_R` | `2.5/365` | 时间步长，年 |
| `elevator_capacity` | 537,000 | 电梯年运力，吨/年 |
| `elevator_cost_per_ton` | 60 | 电梯单位运输成本，万美元/吨 |
| `lambda_elevator` | 0.02 | 电梯年故障计数的泊松参数 |
| `rocket_fault_prob` | 0.0016 | 火箭故障概率 |

脚本通过累计运输量、时间、成本与故障事件，形成模拟分布，并输出统计报告。该实现采用简化运输规则，结果取决于给定假设与参数。

## 已知限制

1. **单位需要区分。** Q1 中的 `C` 数量级与论文对照时使用亿美元尺度；Q2 的成本数组以万美元计，绘图时另转换为万亿美元。归档章节还有不同的单位表述，不能直接混用。
2. **部分注释与赋值不一致。** 例如 Q2 头部注释提到故障参数 0.05，但实际 `lambda_elevator = 0.02`；延误分布的部分“修改前后”注释也与当前赋值不同。执行时以赋值为准，未将注释当作验证依据。
3. **算法保留原状。** 本次整理没有修改模型参数、Pareto 算法、推荐权重逻辑或模拟规则。默认采样量较大且筛选可能较慢。
4. **参数存在重复定义。** Q2 的 `simulate_rocket_trip` 内部再次定义火箭时间、成本与运力。做参数敏感性实验时，需要同时检查主脚本和函数内定义，不能只改顶部参数。
5. **复现链尚不完整。** 目前没有 MATLAB 执行验证、自动化数值测试，也没有覆盖全部图表的生成脚本。论文结果与所选代码版本的逐项一致性尚未核对。
6. **归档不作为主结论来源。** 成本笔记、示例拟合及旧版章节包含历史设定，保留它们是为了追踪建模过程。使用前需核对数据来源、物理含义和尺度。
